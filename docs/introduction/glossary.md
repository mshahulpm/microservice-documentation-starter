# Glossary

Shared terms used across this documentation portal. Add organization-specific terms here. Do not invent unofficial names for real services.

| Term | Meaning |
|---|---|
| Service | A microservice that owns its documentation under `services/` |
| Flow | A documented process owned by the service that orchestrates it |
| Provider | An external system integrated by a specific service |
| Event | A message published or consumed by a service |
| ADR | Architecture Decision Record stored under `docs/adr/` |
